まず最初に：なぜこの解き方をするのか

1. 何を求めているのか

この授業で求めているのは「スイッチを入れてから、電流が時間とともにどう変わるか」、つまり i(t) という時間の関数です。抵抗だけの回路なら V = R I で一発。でも L と C は違います。

  • L の電圧は「電流が変わる速さ」で決まる：vL = L di/dt（微分）
  • C の電圧は「それまでにたまった電荷」で決まる：vC = (1/C)∫i dt（積分）

だから回路の式に微分や積分が入ってきます。微分が入った式を「微分方程式」と言い、これを解くと i(t) が出てきます。授業の解き方が全部微分方程式になっているのは、L と C の性質そのものがそうなっているからです。

2. どの問題も、同じ6段で進む

段やることなぜやるか
①素子の式を書く（vR=Ri, vL=L di/dt, vC=(1/C)∫i dt）電圧を全部「電流 i」で表すため。そうしないと未知のものが多すぎて解けない
②キルヒホッフで回路方程式を作る「一周すると電圧の合計は電源と同じ」「分かれ道で電流は入る＝出る」は、どんな回路でも必ず成り立つ。ここから式をもらう
③余計な電流を消す・t で微分して ∫ を外すi1 と i2 が混ざっていたり、∫ と d/dt が混ざっていたりすると解けない。1種類の電流、微分だけの式にそろえる
④解く（1階なら変数分離、2階なら i = A emt とおく）式の形で決まっている定番の解き方がある（下の3・4）
⑤積分定数を初期条件で決める積分すると必ず定数が残り、答えが1つに決まらない。スイッチを入れた瞬間の値（授業資料のルール）で決める
⑥t=0 と t=∞ を代入して確かめる・時定数とグラフ初期状態・定常状態の値と合えば答えはほぼ正しい。合わなければ符号か係数の間違い

3. 1階（L だけ、C だけ）はなぜ「変数分離」か

RL 直列の式 L di/dt = E − R i を変形すると、di/dt = −(R/L)(i − E/R) になります。これは「変わる速さが、今の値と最終値の差に比例する」という形です。差が大きいうちは速く変わり、差が小さくなるとゆっくりになる。だから曲線はだんだん寝ていく。

この形は、i を左、t を右に分けると両辺をそれぞれ積分できます。そのとき ∫dx/x = log|x| を使いたいので、先に i − E/R のかたまりを作っておきます。かたまりにしないまま積分すると係数が残ってミスが出やすい（2組の先輩の答案がこれで崩れていた）。

4. 2階（L と C が両方）はなぜ「i = A emt とおく」か

RLC 直列は L d2i/dt2 + R di/dt + i/C = 0 という2階の式になり、変数分離では解けません。そこで emt を使います。emt は微分しても m emt、もう1回微分しても m2emt で、形が変わらないただ1つの関数です。代入すると全部の項に A emt が付くので、それで割ると L m2 + R m + 1/C = 0 というただの2次方程式になります。微分方程式が中学の2次方程式に変わるのがこの方法のうまい所です。

5. なぜ「定常解 0、過渡解だけ考える」のか

答えはふつう「最後に落ち着く値（定常解）」＋「途中で消えていく部分（過渡解）」の足し算です。RL 直列では最後に E/R が流れ続けるので、i − E/R の形（最終値との差）を解いていました。RLC 直列では、C がたまりきると電流が止まるので最後の値は 0。だから過渡解だけ考えればよい、と問題文が言っています。

6. 2階では初期条件がなぜ2つ要るか

2回積分したのと同じなので定数が A1, A2 の2つ出ます。2つ決めるには条件が2つ要ります。

  • 1つ目：i(0) = 0（L にはすぐ電流が流れない）
  • 2つ目：vL(0) = E、つまり di/dt(0) = E/L（t=0 では R の電圧も C の電圧も 0 なので、E が全部 L にかかる）

7. 時定数 τ は何のためにあるか

e−t/τ の τ のことで、「変化の速さのものさし」です。t = τ のとき e−1 ≒ 0.37 なので、変化は 63% 済んで残りが 37%。5τ たつと残りは 1% 以下になり、これが「十分時間が経った」の目安です。答案には「e の肩が −1 になる t なので τ = L/R」のように理由も書きます（1組の先輩はこれで満点）。

8. なぜ R2 − 4L/C の符号で3通りに分かれるか

2次方程式の解が「実数2つ」「重解」「複素数」のどれになるかで、emt の中身が変わるからです。回路の意味で言うと、R は電流のブレーキです。ブレーキが強い（R が大きい）と、ゆれずにじわっと 0 に戻る（過減衰）。ブレーキが弱い（R が小さい）と、L と C の間でエネルギーが行ったり来たりしてゆれながら小さくなる（減衰振動）。ちょうど境目が臨界減衰で、いちばん速くゆれずに戻ります。

  • 赤い矢印は「L を電線に描きかえる」という意味。

p4：C にはすぐ電圧が発生しない

  • 「C にはすぐ電圧が発生しない！！」：C の電圧は v = Q/C で、電荷 Q = ∫i dt は電流が流れてだんだんたまる。たまるのに時間がかかるので、t=0 では Q = 0、v = 0。電圧 0 の部品は「ただの線」と同じに見る（電流はふつうに流れる）。
  • L と C は反対になっている所が覚えどころ。t=0 では L＝切れた線・C＝ただの線。t=∞ では L＝ただの線・C＝切れた線（たまりきると電流が止まる。資料にはまだ出ていないが過去問 問1・問3 で使う）。
  • 下の2つ（E-R-C 直列、電流源 I-R∥C）が出そうな形。10/30 の演習と過去問 問3 はこの仲間。

どの問題も同じ4つの道具で解ける

  1. 素子の式：vR = R i、vL = L di/dt、vC = (1/C)∫i dt
  2. キルヒホッフ：電圧は「一周で足すと電源と同じ」、電流は「分かれる点で入る＝出る」
  3. スイッチを入れた瞬間：L は電流ゼロ（切れた線と同じ）、C は電圧ゼロ（ただの線と同じ）
  4. 十分時間がたった後：L はただの線（電圧ゼロ）、C は切れた線（電流ゼロ）

3と4の理由（授業資料 p1〜p4）：L の電圧は L·di/dt なので、電流を一瞬で変えようとすると電圧が無限大になる。だから L の電流はスイッチの瞬間も「前の値＝0」のまま。C の電荷は Q=∫i dt で、たまるのに時間がかかる。だから C の電圧 Q/C もスイッチの瞬間は 0 のまま。時間がたつと電流は一定になり di/dt=0 なので L の電圧は 0、C はたまりきって電流が流れなくなる。

問2（30点）RL 直列：E = R i + L di/dt

(1)(2) 素子の式と回路方程式

vR = R i，　vL = L di/dt，　E = R i + L di/dt

1組の答案は(1)に t=0 の値（0 と E）を書いて丸をもらっているが、問題文は「i を用いて示せ」なので R i と L di/dt を書くのが安全。

(3) 解く（変数分離）

L di/dt = E − R i　⇒　di / (i − E/R) = −(R/L) dt
両辺を積分：log| i − E/R | = −(R/L) t + A（A は積分定数）
i − E/R = B e−(R/L)t　（B = ±eA とおく）
初期条件 i(0)=0 より 0 − E/R = B　⇒　B = −E/R
i(t) = (E/R)(1 − e−(R/L)t)，　時定数 τ = L/R
時定数は「e の肩が −1 になる時刻」。(R/L)t = 1 のとき t = L/R。その時 i は最終値 E/R の 1−e−1 ≒ 63% まで来ている。グラフは 0 から立ち上がって E/R に近づく曲線で、τ の所に E/R(1−e−1) と書き込む（1組の答案はこれで満点）。
2組の答案は log の前に −1/R が付いたまま積分して形が崩れ、i = −E/R(…) と符号が逆になった（4/… の△）。先に i − E/R の形にそろえてから積分すると係数で迷わない。答えを出したら「i(0)=0 になるか」「t→∞ で E/R になるか」の2つを必ず代入して確かめる。

問3（30点）電流源 1A ／ 左に R、右に R と C の直列

(1) t=0

C は電圧 0 の「ただの線」なので、左も右も抵抗 R が1本ずつの並列。同じ R なので 1A が半分ずつ分かれる。

i1(0) = 1/2，i2(0) = 1/2，v1(0) = R/2，v2(0) = R/2，v3(0) = 0
2組の答案は i を 1/R と書いた。電流源の問題では電流の値は 1A をどう分けるかで決まる。R で割るのは電圧源の時の癖。

(2)(3) 回路方程式

1 = i1 + i2　　R i1 = R i2 + (1/C)∫i2 dt

(4) i1 を消して微分方程式に

R(1 − i2) = R i2 + (1/C)∫i2 dt　⇒　R − 2R i2 = (1/C)∫i2 dt
t で微分（定数 R は消える）：−2R di2/dt = i2/C

(5) 解く

di2/i2 = −dt/(2RC)　⇒　i2 = B e−t/(2RC)，　i2(0)=1/2 より B=1/2
i2(t) = (1/2) e−t/(2RC)，　τ = 2RC
なぜ 2RC か：C から見ると、充電の電流は「右の R」と「左の R」を通って回る。だから抵抗が 2R に見え、時定数は 2R×C。t→∞ では C が切れた線になり i2→0、1A は全部左の R へ行く。グラフは 1/2 から下がって 0 に近づき、τ の所で (1/2)e−1。

問4（30点）RLC 直列（今日の演習と同じ）

(1) t=0

i(0) = 0，vR(0) = 0，vL(0) = E，vC(0) = 0
2組の答案は「R i」「L di/dt」と式を書いて△。t=0 の問いは数値（0 や E）で答える。今日の演習の自分の答え（i=0, vR=0, vL=E, vC=0）は正しい。

(2) 回路方程式を t で微分して2階の微分方程式へ

E = R i + L di/dt + (1/C)∫i dt
t で微分（E は一定なので 0）：L d2i/dt2 + R di/dt + (1/C) i = 0
なぜ微分するか：∫ が残っていると解けない。微分すると ∫ が外れて i だけの式になる。E は電池の一定値なので微分すると消える。

(3) 特性方程式（今日の演習の(5)）

i = A emt を代入：L A m2emt + R A m emt + (1/C) A emt = 0
A emt で割って：L m2 + R m + 1/C = 0
1組の答案はここで A emt を消さずに止めて△3。最後の「割って L m2 + R m + 1/C = 0」まで書かないと点が来ない。

(4) m を α と ω0 で（今日の演習の(6)）

m = {−R ± √(R2 − 4L/C)} / (2L) = −R/(2L) ± √{(R/2L)2 − 1/(LC)}
m = −α ± √(α2 − ω02)　（α = R/2L，ω0 = 1/√(LC)）
√ の中の R2 − 4L/C の符号で答えが3通りに分かれる。これが問(7)(8)(9)。

R2 − 4L/C > 0（過減衰。今日の演習の(7)）

β = √(α2 − ω02) とおくと m1 = −α+β，m2 = −α−β（2つの実数）。

i = A1em1t + A2em2t
条件①：i(0)=0 ⇒ A1 + A2 = 0
条件②：vL(0)=E ⇒ L(A1m1 + A2m2) = E
⇒ A1 = E / {L(m1−m2)} = E/(2Lβ)，A2 = −E/(2Lβ)
i(t) = E / (2L√(α2−ω02)) · e−αt ( e√(α²−ω₀²) t − e−√(α²−ω₀²) t )
2つ目の条件がなぜ vL(0)=E か：2階の式は定数が2つあるので条件も2つ要る。1つは i(0)=0。もう1つは「t=0 で R と C の電圧が 0 なので、E が全部 L にかかる」＝L di/dt(0) = E。di/dt(0) = E/L と覚えておくと(8)(9)でも同じように使える。

今日の演習の(8)(9)：過去問に無いので念のため

(8) R2 − 4L/C = 0（臨界減衰）

√ の中が 0 なので m = −α の重解。重解の時は一般解に t が付く。

i = (A1 + A2 t) e−αt
i(0)=0 ⇒ A1 = 0。　di/dt = A2e−αt − αA2 t e−αt，di/dt(0) = A2 = E/L
i(t) = (E/L) t e−αt

(9) R2 − 4L/C < 0（減衰振動）

√ の中が負なので、ωd = √(ω02 − α2) とおくと m = −α ± jωd（複素数）。

(7) の答えの β を jωd に置きかえる：i = E/(2L·jωd) · e−αt(ejωdt − e−jωdt)
オイラーの式 ejθ − e−jθ = 2j sinθ を使う
i(t) = E/(L√(ω02−α2)) · e−αt sin(√(ω02−α2) t)
3つとも t=0 で 0 から出て、最後は 0 に戻る（C がたまりきると電流が止まるから）。違うのは途中の形だけ：過減衰は1回ふくらんでゆっくり戻る、臨界はいちばん速く戻る、減衰振動は＋−にゆれながら小さくなる。下の動く教材で R を動かすと切りかわる所が見える。

動く教材：R を動かして3つの形を見る

E = 10 V。点線は時定数 τ（RL・RC の時）。RLC では R臨界 = 2√(L/C) を境に形が変わる。
